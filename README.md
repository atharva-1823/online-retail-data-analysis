# 📊 Online Retail Data Analysis

## 🎯 Project Overview
This project analyzes transactional data from a UK-based online retail business to uncover insights related to:
- Revenue trends
- Customer behavior
- Product performance
- Country-wise sales
- RFM customer segmentation

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Key Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Revenue Analysis
- Time-Based Trend Analysis
- Country-wise Analysis
- Customer Analysis
- RFM Segmentation
- Visual Storytelling

---

## 🔍 Major Insights
- Revenue exceeded £8.9 million
- UK contributed majority revenue
- Germany emerged as strongest international market
- Peak sales occurred between September and November
- Loyal and high-value customers drove significant revenue

This project demonstrates practical data analyst skills including:
- Data cleaning
